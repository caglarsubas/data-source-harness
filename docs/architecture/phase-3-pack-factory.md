# Phase 3 architecture: reusable pack factory

Phase 3 turns the first reference lab into a reproducible factory pattern without changing the connector ABI or any JSON wire contract.

## Factory flow

1. An `IndustryPackDefinition` describes datasets, fields, generation seed and relationships in industry-pack code—not the core API.
2. `MockDatasetGenerator` resolves dependencies topologically and emits stable JSONL/CSV bytes. Unknown and cyclic references fail closed.
3. `ConnectorScaffolder` reads an already-parsed OpenAPI document as inert metadata and emits a v1 profile, compilable adapter metadata and deployment guidance. It embeds neither endpoints nor secrets.
4. The pluggable `ArtifactSigner` signs a canonical checksum manifest and CycloneDX SBOM. The included HMAC implementation is limited to deterministic offline labs; production publishers must inject an asymmetric or HSM-backed signer.
5. The cold-chain lab certificate compares generated bytes with committed fixtures, validates relationships and manifests, runs an excursion scenario, verifies package identity and checks every Phase-2 schema digest.

## Portability and air-gap boundary

The cold-chain lab exercises relational shipment data, event telemetry, incidents and REST metadata. Building and verifying its connector and lab archives requires no network access. The public core is scanned for terms from the first pilot, and the baseline lock requires the same 14 schemas used by Phase 2.

This proves repeatable synthetic packaging and contract reuse. It does not prove a live carrier connection, production scale, deployed OpenShift behavior, publisher identity, or stakeholder acceptance.
