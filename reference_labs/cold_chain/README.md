# Cold-chain excursion-response reference lab

This second industry pack tests whether the harness factory is portable beyond white-goods manufacturing. It combines relational shipment data, time-series sensor events, carrier REST metadata and incident records. All records and APIs are synthetic.

The lab is evidence for deterministic pack generation, unchanged wire-contract reuse, connector scaffold generation, package integrity and disconnected verification. It is not evidence of production carrier integration, operational deployment or buyer acceptance.
